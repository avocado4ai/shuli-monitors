# Ollama Metrics Monitoring Stack

This repository contains a complete monitoring solution for Ollama LLM deployments, including metrics collection, storage, and visualization.

## Overview

The monitoring stack consists of:
- **ollama-metrics**: A lightweight proxy that sits between your applications and Ollama, collecting metrics while forwarding requests
- **Prometheus**: Stores and queries the collected metrics
- **Grafana**: Visualizes the metrics with a pre-configured dashboard
- **Node Exporter**: Collects system metrics (CPU, memory, etc.)

## Architecture

```
Application → ollama-metrics → Ollama
                   ↓
              Prometheus ← Grafana
                   ↑
              Node Exporter
```

## Quick Start

### Prerequisites

- Docker and Docker Compose
- Ollama running on your host system

### Setup

1. **Start the ollama-metrics service** (if not already running):
   ```bash
   # Make sure the binary is executable
   chmod +x ollama-metrics
   
   # Run with environment variables
   OLLAMA_HOST=http://host.docker.internal:11434 PORT=1313 ./ollama-metrics
   ```

2. **Start the monitoring stack**:
   ```bash
   docker-compose up -d
   ```

3. **Access Grafana**:
   - Open your browser to http://localhost:3000
   - Login with username: `admin`, password: `password`
   - The Ollama Metrics dashboard should be available

4. **Import the dashboard** (if not already configured):
   - In Grafana, go to Dashboards → Browse
   - Click "Import"
   - Upload the `prometheus/dashboard.json` file or paste its content
   - Select the Prometheus data source

## Configuration

### Environment Variables

The ollama-metrics service accepts these environment variables:

- `OLLAMA_HOST`: Address of the upstream Ollama service (default: `http://localhost:11434`)
- `PORT`: Port on which the service listens (default: `8080`)

For Docker environments, use `host.docker.internal:11434` to access Ollama running on the host.

### Prometheus Configuration

The `prometheus/prometheus.yml` file configures metric scraping:
- Scrapes ollama-metrics every 15 seconds
- Also scrapes node-exporter for system metrics

### Grafana Dashboard

The pre-configured dashboard includes:
- Token generation metrics (prompt and generated tokens)
- Request duration metrics
- Token generation time per model
- Loaded models and their RAM usage
- Most used models
- System metrics (CPU, memory)

## Metrics Collected

The ollama-metrics service exposes these Prometheus metrics:

- `ollama_prompt_tokens_total`: Total prompt tokens sent to models
- `ollama_generated_tokens_total`: Total tokens generated by models
- `ollama_request_duration_seconds`: Duration of Ollama requests
- `ollama_time_per_token_seconds`: Time per generated token
- `ollama_loaded_models`: Number of models currently loaded
- `ollama_model_loaded`: Indicator if a model is loaded
- `ollama_model_ram_mb`: RAM usage for each loaded model

## Docker Compose Services

The monitoring stack includes:

- **node-exporter**: Collects system metrics
- **prometheus**: Stores metrics with configuration from `prometheus/prometheus.yml`
- **grafana**: Visualizes metrics with pre-configured dashboards

## Troubleshooting

### Common Issues

1. **No metrics showing in Grafana**:
   - Verify ollama-metrics is running and accessible
   - Check Prometheus targets at http://localhost:9090/targets
   - Ensure the port in `prometheus/prometheus.yml` matches where ollama-metrics is running

2. **Cannot connect to Ollama**:
   - Verify Ollama is running on the host system
   - Check that `OLLAMA_HOST` points to the correct address
   - For Docker, use `host.docker.internal:11434`

3. **Grafana login issues**:
   - Default credentials are `admin`/`password`
   - Check Grafana logs: `docker-compose logs grafana`

### Verification Steps

1. Check if ollama-metrics is running: `curl http://localhost:1313/metrics`
2. Verify Prometheus is scraping: Check http://localhost:9090/targets
3. Confirm Grafana data source: In Grafana, go to Connections → Data sources

## Security Considerations

- Change default Grafana credentials after initial setup
- Restrict network access to the metrics endpoint in production
- Use appropriate authentication for production deployments

## Development

To run the ollama-metrics service locally without Docker:

```bash
# Build the service
go build -o ollama-metrics .

# Run with environment variables
OLLAMA_HOST=http://localhost:11434 PORT=1313 ./ollama-metrics
```

## Files Structure

- `ollama-metrics`: The compiled binary
- `prometheus/dashboard.json`: Grafana dashboard configuration
- `prometheus/prometheus.yml`: Prometheus configuration
- `prometheus/docker-compose.yml`: Original compose file
- `docker-compose.yml`: Main compose file for the monitoring stack
- `.env`: Environment variables (if exists)
- `DASHBOARD.md`: Detailed dashboard documentation
